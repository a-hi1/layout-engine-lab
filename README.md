# 布局引擎实验台

一个纯前端的流程图画布：拖动、框选、成组，点一下把缠绕的连线排成清晰的分层结构。

**单文件 · 零依赖 · 无构建 · 无后端 · 无网络请求**

---

## 在线体验

> https://a-hi1.github.io/layout-engine-lab/

打开即用，不需要任何配置。

---

## 它在做什么

画布上有 18 个节点、34 条连线，画的是一套电商系统的模块依赖。

打开时是乱的：节点互相压着，连线缠成一团。点「自动布局」，0.8 秒内排成 6 列，交叉和重叠同时下降。

右上角两个数字是实时算出来的——**不是评分，是几何事实**。你拖动任何一个节点，它都会跟着变。

## 交互

| 操作 | 效果 |
|---|---|
| **自动布局** | 核心演示，节点归位，数字下降 |
| **打乱** | 换一种乱法（首屏是固定种子，所以每次打开一致） |
| 拖动节点 | 带着连线一起走 |
| 拖动空白 | 平移画布 |
| 滚轮 | 以光标为锚点缩放 0.2× ~ 3.4× |
| `Space` | 切换「移动 / 选择」模式 |
| 框选 | 选择模式下拖动，或按住 `Alt` |
| 成组 / 解散 | 选中 ≥2 个节点后成组，拖动任一成员带动整组 |
| `Ctrl/⌘ + Z` | 撤销 / 重做，最多 60 步 |
| 快捷键 | `L` 布局 · `R` 打乱 · `Esc` 取消选择 |

## 算法

分层图绘制的简化实现，四步：

### 1. 分层（最长路径）
对每条边 `a → b` 反复松弛 `layer[b] = max(layer[b], layer[a] + 1)`。
一个节点一定排在它所有前驱的右边，**依赖关系从左到右一眼能读**。

### 2. 层内排序（barycenter）
每层内部按「相邻层邻居位置的平均值」排序，上下交替扫描 5 轮。

### 3. 坐标分配
第 `c` 层 → `x = (c - (n-1)/2) * COL_GAP`；层内第 `k` 个 → `y = (k - (m-1)/2) * ROW_GAP`。

### 4. 局部交换优化
barycenter 是启发式，不保证最优。最后再做一轮爬山：每层试相邻换位，交叉数下降就保留，否则换回。

---

## 两个指标怎么算

**连线交叉**：每条边当作起终点中心连线，两两做线段相交测试，共用端点的不计。

**节点重叠**：两两比较包围盒，横纵中心距同时小于 0.92 倍节点尺寸即算一对。

两个都是几何计算，可复现、可解释。

## 实现要点

- **Canvas 2D** 单画布渲染，`devicePixelRatio` 适配高分屏
- 零依赖，没有框架、构建工具、CDN
- 状态很小：`nodes / edges / groups / view / selection / history`
- 动画走 `requestAnimationFrame`，并带 `setTimeout` 兜底：
  切后台导致 rAF 被节流时，布局和视图也会在超时后强制落位，不会卡在中间态
- 历史记录用整图快照（60 步上限），比命令式 undo 简单且不会漏状态
- 分层有环保护：即使输入图存在环，层号也不会失控
